The **Wardrobe** is an outfit storage building which is only accessible via console commands and is yet to be added to ***The Forest***.

## Gameplay

The **wardrobe** is a possible new building that was most likely added into the game files in v1.11. It cannot be built normally as of yet and is only accessible via console commands
To add the **wardrobe**, you must first enable console commands which is only available on PC, and not PS4.

* Active console commands by typing `developermodeon` in the main menu, you just have to type it, there is no special box or anything, just type it.
* Enter a game, then press `F1`
* Type in `PlaceBuiltObjects Wardrobe_Built 1` and this will spawn it in front of you, it will always be facing west
* If you wish to add the blueprint, type in `placeallghosts` which will add every blueprint in the game, one of them will be the wardrobe
