The **tree bridge** is a elevated structure that uses logs to form bridges between specific kinds of buildings, it was added in update v0.10 of ***The Forest***

## Gameplay

The **tree bridge** can connect to some of the other buildings in the game. Over long distances it does start to hang low, so it is better used over shorter distances. It can be used to create 'ewok' type villages as well. The longer the **tree bridge** is, the more logs it will cost. The following buildings have certain amount of anchors that the **tree bridge** or climbing rope can attach to:
Gazebo (2), Log Cabin (2), Platform (2), Tree Platform (4), Cliff Side Platform (3) Platform (4), Simple Stairs (2) and Basic Wall (2)

Tree bridges can make a cheaper and easier replacement for custom stairs. They can be run for long lengths and at fairly steep angles to create ramps up cliffs or up to platforms. Simple Stairs and Cliff platforms are the cheapest anchor points.
