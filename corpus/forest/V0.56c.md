**v0.56c** Was the second small hotfix for update v0.56 and was released on 13 March, 2017.

## Dev Notes

V56c – hotfix
Posted on 13 March, 2017 by Anna

Hey Everyone,

Here is another small memory fix. This time lowering the amount of memory used by initializing the save game screen.

As a result of this change, old save games will no longer display the difficulty text, until you open and re-save them.

## Additions / Changes / Fixes

* Fixed excessive memory when opening save menu which could often result in out of memory crashes when saving.
