The **wall weapon rack** is a weapon storage structure that was added in update v0.30 of ***The Forest***. It is a variant of the Ground Weapon Holder is hidden under the same name.

## Gameplay

There are two variations for the **Wall Weapon Rack**. The type is determined on where the player is trying to place it. If aimed at the floor it will become the **floor weapon rack**, which looks like a stump. When attempting to place it on the wall it will become the **Wall Weapon Rack**. Both have different uses and costs associated with them. Some weapons and tools don't look very good on them though this is up to the player. The Turtle Shell and Repair Tool cannot not be placed on these racks. All these racks here only hold one weapon or tool. If you wish to store more, consider using the weapon rack instead, which holds 4 weapons.

## Storage

The **wall weapon rack** can store one of the following weapons/tools:  
 Chainsaw  
 Climbing Axe  
 Club  
 Crafted Axe  
 Crafted Bow  
 Crafted Club  
 Flare Gun  
 Flintlock Pistol  
 Incendiary Spear  
 Katana  
 Machete  
 Modern Axe  
 Modern Bow  
 Rusty Axe  
 Slingshot  
 Tennis Racket  
 Upgraded Spear  
 Upgraded Stick  
 Weak Spear  
  
It **CANNOT** store the following weapons/tools:  
 Plane Axe  
 Repair Tool  
 Turtle Shell
