# Broken Plane

Categories: Item, Story
Revision: 67321

**Infobox: Broken Plane**
**Description**
- **Also known as:** Yellow Plane
- **Added in:** V0.08
- **Item type:** Story

The **Broken Plane**, also called **Yellow Plane** in the game files, was an object that existed on the map in previous versions of the game. It was an invisible plane that casted shadows and could be jumped on and ran into, and it is possible that it is an Easter Egg. It may also be involved in the story, possibly being the source of the Survivor movie producers. When opening a decompiled version of the plane's 3d model, you can see that the plane is a small, high-wing, single-engine piston plane (likely only holding a very small group of people). It has a tail section, broken main wings, and its nose is bent and smashed. Some files were in the game code since v0.01 but the model was added in v0.08 and it was removed in the next update.
