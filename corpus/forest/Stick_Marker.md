**Stick markers** are buildings that add a marker to the HUD to allow players to mark and remember locations, they were added in update v0.03 to ***The Forest***.

## Gameplay

**Stick markers** can be found in the utility structures tab of the survival guide. Stick markers will create a flag icon that is visible from anywhere in the world (similar to the home icon created by shelters). The markers can be turned off by turning off the HUD in the settings or by switching the color to grey.

It should be noted that the stick marker has only a limited number of colors.
