The **small wall** is an unimplemented building in ***The Forest***.

## Gameplay

The **small wall** can only be obtained by spawning using console commands. The current command for it is `PlaceBuiltObjects Ex_SmallWallChunkBuilt 1`. This will place one, change the number at the end to place more at once. It can somewhat be stacked, though difficult, the player needs to stand still when spawns them. It doesn't have a custom placement. It is unknown if mods can allow this building to be placed normally.

## Theory

It is not known why the **small wall** hasn't been implemented. It is possible that its purpose is limited in the developers perspective. It might be a log alternative for stick fences and bone fences.
