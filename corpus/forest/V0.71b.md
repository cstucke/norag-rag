Version **0.71b** was a hotfix released December 19, 2017.

## Dev Notes

Hey everyone,

Here are some fixes and improvements to last weeks v0.71 release. Including some balance of the new calorie system.

## Additions, Changes, & Fixes

| Version | Changes |
| --- | --- |
| **v0.71b** | Fixed dying with toggle crouch on causing issues in hanging cutscene |
| **v0.71b** | Fixed old saves resetting the strength stat value (if not saved over) |
| **v0.71b** | Calories system balance pass, should make weight and strength more manageable |
| **v0.71b** | Fixed dried meat eaten from inventory having the calories applied twice |
| **v0.71b** | Added calories display in stats page |
| **v0.71b** | Fixed blue berries, soda, fish, generic meat and oysters yielding wrong calories amount or having wrong displayed amount |
| **v0.71b** | Fixed crafting recipes with overlapping ingredients and different costs not completable before having done the recipes will fewer ingredients. It will now check all valid recipes and pick the completed one with highest amount of ingredients, completing ones with fewer ingredients can be achieved by having less ingredients on the crafting mat than other recipes require (i.e.: it is now possible to make rabbit fur boots before the small rock bag) |
| **v0.71b** | Fixed shoes vanishing when on turtle shell sled |
| **v0.71b** | Fixed colliders on tennis players being too large |
