# Birdseye
Source: https://theforest.fandom.com/wiki/Birdseye
Categories: Achievement
Revision: 74698

## Description

*Kill bird with arrow*

## Guide

Currently obtainable in Single player & Multiplayer.

Kill any bird with any arrow using either the crafted bow or modern bow to obtain this achievement. It's easier if the bird is on the ground.

### Requirements

killing a bird with the crafted bow or modern bow
