# Make it Rain
Source: https://theforest.fandom.com/wiki/Make_it_Rain
Categories: Achievement
Revision: 74726

## Description

*Set off the sprinklers in end game*

## Guide

Currently obtainable in Single player & Multiplayer.

This is a hidden achievement in the game and can be completed once you have entered the Sahara Laboratory.

There are a few different hallways where you look above and see the sprinklers in the ceiling. For example, one hallway contains an Armsy that you need to get past in order to continue forward. Simply shoot a Fire Arrow or a Flare at the Armsy or down one of the hallways with the sprinklers in order to set them off and complete this achievement.

It is also possible to set off the sprinklers in the hallway or some of the offices by lighting weapons with a cloth attached to them on fire.

### Requirements

Set off the sprinklers using fire  
 Rebreather to access the location  
 Climbing Axe to access the location  
 Keycard Two to access the location
