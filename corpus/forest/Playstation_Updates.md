# PS4 v1.15

**PS4 V1.15** was a patch released February 6th, 2019.

## Dev Notes

Hey Everyone,

We have just released a small patch for the PS4 version of The Forest. This patch improves overall stability and also fixes a bug with the hole cutter display.

## Additions, Changes, & Fixes

* Improved stability and memory usage
* Fixed an issue where some hole cutter structures would show wrong outline

# PS4 v1.14

**PS4 V1.14** was a patch released January 25th, 2019.

## Dev Notes

Hey everyone,

This patch for PS4 adds the camcorder pickup, along with some various fixes and improvements.

## Additions, Changes, & Fixes

* Added fix for camcorder
* Fixed snow stumps popping in too soon
* (multiplayer)Fixed a performance issue with loading into big saves when far away
* Fixed missing pickup icon on rabbit in a cage
* Fixed missing can't carry anymore bolts message when at maximum
* Fixed wrong underscore in crossbow bolts message text
* Fixed wrong log material on in progress dog effigy model
* (balance) Tweaked amount of damage one of the late game creatures can do to structures
* (balance) Lowered amount of protection from creepy armor
* Fixed hang glider unusable after completing alternate ending
* Fixed hang glider disappearing after saving and loading while holding the glider
* Fixed an issue with late game creature that could cause a freeze or stutters
* Fixed a stability issue caused by exiting to main menu
* (multiplayer) Added option for increased player to player damage in multiplayer games

# PS4 v1.10

**PS4 v1.10** was a patch released December 11th, 2018.

## Dev Notes

Hey Everyone,

We’ve just released a patch for PS4.

This fixes some bugs unique to PS4 from last nights patch release including:

Thanks to all the players who helped us find these bugs, please continue to post in https://www.reddit.com/r/TheForest/ with any issues and suggestions you have.

We have seen some players mention the missing camcorder on playstation, we have been trying several fixes for this, However, there is an issue with video playback in the unity version for playstation we are using. We are hoping to be able to solve this soon.

The team at endnight

## Additions, Changes, & Fixes

* Fixed low movement speed after using hang glider
* Fixed additional hang glider bugs
* Fixed case where end boss could vanish if no players were around
* Fixed an area you could fall through in ocean

# PS4 v1.09

**PS4 v1.09** was a patch released December 11th, 2018.

## Dev Notes

Hey Everyone,

We’ve just released our 1.09 patch for Playstation! This update includes two new late game creatures, a new crossbow weapon, a buildable hang glider and lots more. To find the new buildables you're going to need to find the caves they are hidden in.

In addition to this we’ve also improved stability of the game, and fixed some minor bugs.

Note: you'll need to make sure in multiplayer that whoever you are playing with is also on the current build for things to work correctly.

## Additions, Changes, & Fixes

No notes listed, this update is essentially v1.10 for PC, check the notes there for a guide.
