# Succès
Source: https://theforest.fandom.com/wiki/Succ%C3%A8s
Categories: Succès
Revision: 72401

***The Forest*** an apporté son lot de **succès** Steam lors de la mise à jour v0.64 qui inclue 45 **succès**, don't 6 cachés. Certains **succès** sont accessibles uniquement en mode multijoueur. Tous les autres **succès** peuvent aussi bien être obtenus en solo ou en multijoueurs.

| Nom | Icône | Description | Obtention |
| --- | --- | --- | --- |
| Be Nice |  | Partager de la nourriture ou une boisson en multijoueur | *(Multijoueur seulement)* Combinez votre plateau en métal avec un autre objet dans l'inventaire de crafting et équipez-vous en, puis donnez-le à un autre joueur. |
| Be Extremely Nice |  | Partagez une arme en multijoueur | *(Multijoueur seulement)* Combinez votre plateau en métal avec une autre arme dans l'inventaire de crafting et équipez-vous en, puis donnez-le à un autre joueur. |
| First Responder |  | Faites revivre un joueur en co-op | *(Multijoueur seulement)* Faites revivre un joueur en mode multijoueur, avant que celui ne meurt. Les joueurs tués par des requins ou noyés ne peut être sauvés. |
| Medic |  | Faites revivre dix joueurs en co-op | *(Multijoueur seulement)* Faites revivre 10 joueurs en mode multijoueur, avant que ceux-ci ne meurent. Les joueurs tués par des requins ou noyés ne peut être sauvés. |
| Camp Out |  | Dormir avec un autre joueur (nuit en groupe) | *(Multijoueur seulement)* Vous devez dormir dans le même abri qu'au moins un autre joueur pour obtenir ce succès. |
| Minor Cannibalism |  | Mangez un ennemi | Vous devez manger 2 bras et 2 jambes. Ils peuvent être cuits sur le feu, séchés sur l'étendoir, ou mijotés. Couper les membres réduira l'état mental de 1 par membre, tandis que les manger le réduira de 3 par membre. |
| Major Cannibalism |  | Mangez une famille entière | Vous devez manger 12 bras et 12 jambes. Ils peuvent être cuits sur le feu, séchés sur l'étendoir, ou mijotés. Couper les membres réduira l'état mental de 1 par membre, tandis que les manger le réduira de 3 par membre. |
| Trophy Hunter |  | Tuez tous les animaux et mettez-les sur les trophées | Voir Trophée de Tête ou Tête d'Animal (Les têtes d'oies sont particulièrement difficiles à obtenir). |
| Splatter |  | Abattre un ennemi avec une pierre | Utilisez une pierre, mais pas la pierre améliorée. |
| Choppy Chop |  | Hachez 50 corps | Pour chaque corps, vous devez enlever tous leurs membres, c-à-d les deux bras et les deux jambes. |
| Commercial Fisherman |  | Tuez 6 poissons ou plus avec une dynamite | Les petits points d'eau dans le jeu contiennent seulement 3-4 poissons en même temps. Pour compléter ce succès, vous devez trouver de grands points d'eau où apparaissent beaucoup de poisons, tels que le (Geese Lake) (lac des oies) ou le long de la côte. Une fois ce point trouvé, allumez une dynamite et jetez-la la plus proche possible du groupe de poissons. Ne la jetez pas au milieu de l'eau ou la dynamite s'éteindra. Alternativement, vous pouvez utiliser une bombe, que vous pourrez jeter dans l'eau. |
| Serial Killer |  | Tuez 100 cannibales | La plupart des joueurs complèteront naturellement ce succès au bout d'un certain temps aussi bien en solo qu'en multijoueur. La manière la plus rapide pour compléter ce succès est de poser des pièges dans une zone fréquentée par les cannibales et d'allumer un feu de joie pour attirer de large groupe de cannibales. |
| Bite me! |  | Tuez un requin | Tuez un requin. Une bombe collante se collera au requin et le tuera. Les armes à longue portée sont aussi recommandées. Un requin tuera un joueur en 2-3 morsures. Ils ne peuvent être attaqués sous l'eau et se situent seulement dans certaines zone d'eau. |
| Monster |  | Tuez un lapin | Le plus simple pour tuer un lapin est d'utiliser une arme à distance, telle que l'arc, le lance-pierre ou une pierre jetable, mais vous pouvez aussi essayer de le tuer avec le Katana ou tout autre méthode. Un piège à lapin peut être plus facile mais assez aléatoire au niveau du temps. |
| Birdseye |  | Tuez un oiseau avec une flèche | Tuez n'importe quel oiseau avec n'importe quelle flèche en utilisant soit l'arc crafté soit l'arc moderne. Il est plus facile d'accomplir ce succès lorsque les oiseaux sont au sol. |
| Fisherman |  | Attrapez un poisson avec un piège | Construisez un piège à lapin dans l'eau à une zone où les poissons passent. Il vous faut être sûr que le piège à lapin passe bien en piège à poisson. |
| Green Thumb |  | Faites grandir toutes les plantes | Faites grandir les myrtilles, l'échinacée, et l'aloé. Les myrtilles grandiront seulement au jardin, pas dans la jardinière murale. Les champignons ne sont pas requis pour ce succès. |
| Naturopath |  | Créé 10 objets médicaux | Créez des herbes médicinales et herbes médicinales+. Les mix énergétiques et mix énergétiques+ ne sont pas nécessaires. |
| Gabe Fan |  | Collectez des cassettes | Voir **lecteur de cassette** or **cassettes** |
| Unseen |  | Faire et porter une armure de camouflage | Abattez plusieurs buissons jusqu'à 15 feuilles, tuez lézard ou crocodile et récupérez la peau, combinez 15 feuilles et 1 peau de lézard puis équipez-vous d'une armure de camouflage. |
| Longest Wall |  | Build a super long wall | All you need to do is place the "blueprints" for your wall. The player must make sure to make a custom wall as the defensive wall does not work towards this achievement. |
| Demolition Man |  | Set off 20 bombs | Go into your inventory and equip your bombs, and simply throw one to set it off. Dynamite, Sticky Bombs, and Head Bombs possibly also count towards it. See **bomb** for more information. |
| Boy Scout |  | Utilisez la boussole | Allez dans votre inventaire et équipez-vous en. Voire **boussole** pour plus d'informations. |
| Handyman |  | Réparer un abri | Construisez un abri de chasse, frappez-le avec une arme faible (ex. un bâton amélioré) et utilisez votre outil de réparation. |
| Climate Change |  | Couper 100 arbres | Coupez 100 arbres en utilisant une hache, une tronçonneuse ou un explosif. Les bâtons ne comptent pas. |
| Don't Save The Forest |  | Couper 1000 arbres | Pareil que le succès Climate Change. Voir Don't Save The Forest pour plus d'informations. |
| Demolition Expert |  | Détruire 6 arbres ou plus avec 1 explosif | Trouvez un groupe d'arbres, équipez-vous d'un explosif et jetez-le au milieu des arbres. |
| Crafty |  | Créer 26 items spécifiques | Voir **Crafty** and/or **Crafting**. |
| Good Father |  | Collecter toutes les pièces de robot | Voir jouet. Une fois que vous avez toutes les pièces, allez dans votre inventaire et combinez chaque pièce afin d'obtenir le succès. |
| Vegan |  | Jouer toute une partie sans tuer ni manger un animal | Voir Vegan - Un des succès les plus difficiles dans le jeu. |
| 5 Star Hotel |  | Dormir sur le yacht | Dormir dans le lit sur le yacht; ce dernier est situé dans la péninsule sud. Attention aux 2 requins qui rôdent à côté. |
| First Night |  | Survivre 1 nuit | Survivre la première nuit. Vous pouvez dormir pour la passer. |
| You are a fun guy |  | Manger tous les types de champigons | Voir champignons. |
| Survivalist |  | Survivre 5 nuits | Survivez 5 nuits dans le jeu. |
| Pacifist |  | Ne tuer aucun cannibales 10 jours d'affilés | Jouer en veganmode fonctionne (à vérifier). |
| Spelunker |  | Explorer toutes les grottes | Un succès assez complexe dû à la longueur des grottes, aux cannibales et aux mutants. Explorez les différentes grottes sur plusieurs parties ne permet pas de les combiner. |
| Get Closure |  | Trouvez tous les passagers manquants | Voir **Passagers** pour plus d'informations. |
| Step Master |  | Faire 50,000 pas | Voir Podomètre (ne se combine pas si vous quittez le jeu puis reprenez la sauvegarde). |
| Survive The Forest |  | Finir le jeu | Voir **Histoire**. |
| Bad Father |  | Survivre 100 jours | Ne peut être fait que sur une sauvegarde (Ce succès ne prend pas en compte le cumul des sauvegardes sur les autres emplacements). |
| Make it Rain |  | Activez les arroseurs en fin de jeu | Ce succès peut être fait en tirant des flèches de feu ou avec le pistolet de détresse, particulièrement face à l'armsy dans le hall à la fin du jeu. |
| Gross! |  | Buvez dans la fontaine à eau qui contient une tête | La fontaine se situe dans le laboratoire de Sahara, dans l'une des salles à droite menant au second artefact. |
| You should be looking for Timmy |  | Construire un belvédère | Construisez un belvédère. Plus c'est proche du sol et plus vous économiserez de bûches et de bâtons. |
| Daily Grind |  | Buvez à machine à café | Les machines à café sont dans le laboratoire de Sahara à la caféteria. |
| Big Spender |  | Acheter une canette de soda et une barre énergisante d'une machine | Les machines sont dans le laboratoire de Sahara à la caféteria. |
