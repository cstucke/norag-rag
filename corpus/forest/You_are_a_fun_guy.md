# You are a fun guy
Source: https://theforest.fandom.com/wiki/You_are_a_fun_guy
Categories: Achievement
Revision: 74876

## Description

*Eat all mushroom types*

## Guide

Currently obtainable in Single player & Multiplayer.

### Requirements

eating all mushroom types from below:  
 Puff Mushroom  
 Chanterelle Mushroom  
 Deer Mushroom  
 Liberty Cap Mushroom  
 poisonous Jack Mushroom  
 poisonous Amanita Mushroom

### Console Commands Method

Some mushrooms can be difficult to locate, such as the Puff Mushroom. Console Commands can be used to add the mushrooms.

|  | Name | Add Item |
| --- | --- | --- |
|  | Amanita Mushroom | `additem 115` |
|  | Chanterelle Mushroom | `additem 116` |
|  | Puff Mushroom | `additem 275` |
|  | Liberty Cap Mushroom | `additem 276` |
|  | Jack Mushroom | `additem 277` |
|  | Deer Mushroom | `additem 278` |
|  | All items (mushrooms included) | `addallitems` |
