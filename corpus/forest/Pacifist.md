# Pacifist
Source: https://theforest.fandom.com/wiki/Pacifist
Categories: Achievement
Revision: 74705

## Description

*In Single Player, don't kill any cannibals for more than 10 days in a row*

## Guide

It can only be obtained in Single Player. You can use same commands as in Bad Father achievement to speed things up.

## Requirements

Not killing cannibals for more than 10 days in a row

## Bugs

* Potentially unable to get achievement if cannibals kill each other. [Needs verification, but I went 14 in-game days without killing any but came across dead cannibals making it possible it affects it. Further speculation by how I got Serial Killer, kill 100 cannibals, while not killing them making it likely the game registers any cannibal death towards you killing them.]
