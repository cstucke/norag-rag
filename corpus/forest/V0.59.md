**v0.59** added support for players to create their own dedicated servers and was released on 18 April, 2017.

## Dev Notes

V0.59
Posted on 17 April, 2017 by Anna

Hey everyone,

This is a small patch release adding support for players to create their own dedicated servers. We’ve set the dedicated server tool to release at 6pm PDT, however the patch of the main game to work with the tool should be released now.

As this is a first pass, it should be considered highly experimental. For the majority of players we recommend continuing to play the game in peer 2 peer mode whilst the final issues with dedicated server functionality are ironed out.

For detailed information about how to set up your own server, visit: http://steamcommunity.com/sharedfiles/filedetails/?id=907906289

## Additions / Changes / Fixes

* Added experimental support for players to host their own dedicated servers
* Added new dedicated server tool (downloadable via tools menu in steam)
* Fixed grabbing a sled partially in water sometimes resulting in all following interactions no longer working
