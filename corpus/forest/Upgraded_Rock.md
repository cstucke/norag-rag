The **Upgraded Rock** is a craftable tool and melee weapon that was added in update v0.07 of ***The Forest***.

## Gameplay

It can be crafted from the player's inventory with one rock and one cloth. Once crafted, it will become a separate tool from regular rocks.

The **Upgraded Rock** can only receive glass upgrades. It can be set on fire using the lighter, but doing so will cause instant burning damage to the player.

As a weapon, the **Upgraded Rock** swings very slowly and consumes a lot of stamina, but deals a fair amount of damage and has a good knockdown power. Despite not being a very interesting tool or weapon, the **Upgraded Rock** is a bloody way to kill enemies lying on the ground.

## Trivia

* Up until v0.72, the **upgraded rock** had a listed block level of 10, which is the highest possible. Though the upgraded rock could never actually block attacks.
* If a player attempts to light the rock on fire using the lighter it will instead set the player on fire.
* The **upgraded rock** used to be able to be painted with blue paint and orange paint, however these items were removed in v1.0
