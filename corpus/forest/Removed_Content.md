# Removed Content
Source: https://theforest.fandom.com/wiki/Removed_Content
Categories: Removed content
Revision: 62243

This page contains content that has be removed from the game. Their articles will provide more information:

* Steps
* Large Drying Rack
* Wooden Path
* Head Effigy
* Map cave 2
* Map pieces
* Mountain Area Grave
* Previously, a large part of the formula for raising strength or athleticism was determined by the tree count - how many trees you cut down in a day. This has been removed with a simpler system put in place.
