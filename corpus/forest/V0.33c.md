**v0.33c** was a hotfix update for v0.33 that released on February 19, 2016.

## Dev Notes

v0.33c – hotfix
Posted on 19 February, 2016 by Anna

Hey Everyone,

We had some reports of massive performance drops in some save games due to yesterday's patch. It turned out to be two separate issues, one with the rabbit fur boots sound dampening, and another where fires were throwing errors which can tank cpu performance. Thanks again everyone for sending us save games to help figure out the issue!

We also fixed a couple other small issues, listed below.

As always, please continue to post your bug reports and feedback in the Discussions area of the Community Hub

## Additions / Changes / Fixes

* Fixed performance issues in save games where players had rabbit fur boots
* Fixed clients getting kicked when foundation with fire on top is destroyed by an explosive
* Fixed an issue with armor values for new armor system
* Added compatibility with new system to previously equipped armor pieces
