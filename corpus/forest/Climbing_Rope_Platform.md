The **climbing rope platform** is a building which is only accessible via console commands though can be found in caves, it was added to ***The Forest*** in v1.0.

## Gameplay

The **climbing rope platform** is a building that cannot be built by the player though it can be found inside caves. It cannot be built normally as of yet and is only accessible via console commands
To add the **climbing rope platform**, you must first enable console commands which is only available on PC, and not PS4.

* Active console commands by typing `developermodeon` in the main menu, you just have to type it, there is no special box or anything, just type it.
* Enter a game, then press `F1`
* Type in `PlaceBuiltObjects ?` and this will spawn it in front of you, it will always be facing west (Command is currently unknown)
* If you wish to add the blueprint, type in `placeallghosts` which will add every blueprint in the game, one of them will be the **climbing rope platform**
