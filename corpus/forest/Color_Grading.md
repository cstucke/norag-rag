# Color Grading
Source: https://theforest.fandom.com/wiki/Color_Grading
Categories: Gameplay
Revision: 73834

**Color Grading** is a setting that changes the filter for the game, allowing the game to have a different look. Certain color grading types can allow the player to see better at night time or within caves such as M131.  
It is possible that color grading is highly dependent on players monitor and graphics card.  
It is recommended for the player to experiment with each during the day and at night time to find which is most suitable.
