# Gabe Fan
Source: https://theforest.fandom.com/wiki/Gabe_Fan
Categories: Achievement
Revision: 74719

## Description

*Collect all cassette tapes*

## Guide

Currently obtainable in Single player & Multiplayer.

### Requirements

all Cassette Tapes

### Locations

| Name | Song Name | Map |
| --- | --- | --- |
| Cassette 1 | Fatal Request - "Stronghold" | - On the Yacht with the Cassette player. |
| Cassette 2 | The Slaps - "No Conscience" | - At the end of Cave 4. |
| Cassette 3 | Frankie Millionaire - "Do It" | - Cave 10, near the cowman and the boat. |
| Cassette 4 | Wolf on Fire - "The Haunting" | - It spawns in Cave 2 in a large open room in a corner that can be found by skull lanterns and it is near mining hats. |
| Cassette 5 | Rick Gold - "Strength, Ability and Wisdom" | - On the Beachside Grave.  - Also spawns in Cave 1 in the mouth of a decapitated head on the path down to the Latin Paper. |

## Trivia

* The name of this achievement may refer to the game's composer, Gabe Castro.
