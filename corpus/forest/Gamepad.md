# Gamepad
Source: https://theforest.fandom.com/wiki/Gamepad
Categories: Gameplay
Revision: 72279

**Gamepads** are controllers that can be used to play ***The Forest***. Support for **gamepads** were added in v0.18. Since the announcement of PS4 release, the developers have been heavily focused on support for **gamepad** controllers, trailers can be seen on the trailers page.

## Gameplay

In v0.25, a new gameplay option was added for “Advanced controller support (XInput)” which is required to use the game with a Steam Controller, it is off by default so check out options if you need it.

The controls page contains the bindings for the game. Most, if not all buttons can be assigned to **gamepads**.

## Supported Gamepads

* PlayStation 4 Controllers
* Xbox Controllers
* Steam Controllers
