The **rock path** is a custom decoration building that was added in update v0.38 to *The Forest*.

## Gameplay

Rock paths can be placed and extended like custom walls, conforms with terrain when placed, cuts grass when built.

As of patch v0.66, rock paths can be removed by using the Hole Cutter. If the path is removed, the grass will regrow when reloading the game.
