# Patch release guide
Source: https://theforest.fandom.com/wiki/Patch_release_guide
Categories: Help
Revision: 50218

This page to make updating The Forest Wiki patches more streamlined as there are quite a few things that need to be updated.

## When any patch is released

* Create new page with the new updates name: Add lowercase template at the top and Versions template at the bottom of the patch page
* Update current patch version: Update current patch version - Currently set at: V1.12 - VR
* Update current patch date release: Update current patch versions date of release - Currently set at: September 11, 2019
* Add new version to the versions template: Update versions template
* Add patch notes to formatted version (not necessary): Patchnotes Formatted

## When a major patch is released

* Complete the above section plus the following:
* Main page countdown timer: Update timer until next major patch for main page
* Current major update: Update current major patch - Currently set at: v1.12 - VR
* Current major update date: Update current major patch date of release - Currently set at: September 11, 2019
* Current major update change: Update major patch changes for main page
