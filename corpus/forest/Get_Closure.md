## Description

## Guide

Currently obtainable in Single player & Multiplayer.

### Requirements

Passenger Manifest  
Finding all the Passengers in a single game.

### Console Commands Method

1. In the main menu type in `developermodeon`
2. Start a game, a new one in this example
3. Collect the Passenger Manifest from the back of the plane
4. Press `F1` and type `findpassenger 1`
5. Press `F1` again - This opens the console
6. `UP ARROW` - This duplicates the last command
7. `DOWN ARROW` - This goes to the end of the command instead of the start.
8. `BACKSPACE` - Remove the numbers
9. Then type in the new numbers.
10. Rinse and repeat
